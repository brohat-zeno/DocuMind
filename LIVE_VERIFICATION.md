# DocuMind handbook live verification

Date: 2026-10-27 (Asia/Kathmandu).

This report describes a fresh run using only the synthetic
[handbook PDF](tests/fixtures/handbook.pdf). Demo identities and email addresses
are fictional. Private historical evidence is kept locally, excluded from Git,
and is not the evidence for any result below.

## Method and configuration

The existing DocuMind Docker image was started with `docker compose up -d --no-build`.
The new named volumes were empty before this run. Groq chat used
`openai/gpt-oss-20b`; local FastEmbed used `BAAI/bge-small-en-v1.5`.
Qdrant, Redis, and SQLite were real services/storage, without test fakes.

```sh
BASE_URL=http://127.0.0.1:8001 bash verification/demo.sh
docker compose exec -T documind-app python < verification/measure_retrieval.py
```

Both commands exited 0. The demo uses curl's `--fail-with-body` option and
paces chat requests by 12 seconds. The API readiness request for a nonexistent
document returned HTTP 404. The live demo made two uploads and eight chat requests.
Read-only SQL, Redis, and Qdrant inspection verified the resulting persisted state.
The vector settings observed were 384 dimensions and cosine distance; retrieval
settings were top-k 5 and threshold 0.58, with size 800 and overlap 100.

Raw synthetic responses and storage readback are in
[handbook-live-results.json](verification/handbook-live-results.json).
The exact questions are in [demo.sh](verification/demo.sh).

## Limits

This run did not verify cancellation, invalid-field correction, slot conflicts,
booking interruption, concurrent requests, long-term TTL expiration, OpenAI
provider success, scanned-document OCR, or production-scale performance.
Deterministic tests cover several of those conversation branches with fakes;
passing them does not establish real-model behavior. No latency distribution
or broad retrieval-quality claim is made. The default threshold is not a
universal relevance boundary. Earlier files retained under `verification/`
are historical development records and must not be mistaken for this run.
